# MODEL-ROUTING-001

## 目标

先统一 Shanforge 事实源、收拢当前工作区并证明干净克隆全绿，再以 Sol 作为总体设计与流程控制模型，对任务分级并授权 Terra 或 Luna 执行。

## 验收标准

- 正式文档、`.factory/project.json`、当前 memory 与 ledger 对当前产品边界和阶段无冲突。
- 当前工作区和干净克隆使用同一正式命令验证通过。
- 模型路由复用 `using-shanforge`，不新增平台运行时或模型路由服务。
- Sol 负责总体设计、任务分级、路由和升级；Terra/Luna 只执行已授权任务，不得自选等级或自批完成。
- 路由规则有确定性结构测试和代表性正反例。

## 范围

- 统一当前项目事实源和必要恢复摘要。
- 清理、归属并提交当前工作区已有变更，保留无关用户改动。
- 修复仓库正式测试和静态门。
- 更新工作流设计、核心 Skills、测试、用户指南和必要 memory。

## 非目标

- 不恢复已删除的 `src/` 平台运行时。
- 不新增模型网关、数据库、服务、依赖或中心 CLI。
- 不执行 push、PR、merge、部署或生产动作。

## 状态

`active`
