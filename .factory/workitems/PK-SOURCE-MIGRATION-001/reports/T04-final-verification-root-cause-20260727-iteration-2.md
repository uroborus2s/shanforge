# PK T04 最终验证根因报告（Iteration 2）

- Task：`PK-SOURCE-MIGRATION-001-T04`
- status：`root_cause_found`
- implementation_performed：`false`

## 直接原因

四份 Registry 已登记任务简报没有产生测试要求的任一任务语义字段，导致 T04
“所有登记简报均有人类可读语义”的关闭门失败。

## 根源原因

任务简报登记与语义解析没有共享一个可验证 schema：

- Registry 按目录接受全部 Markdown；
- 解析器在正则和映射中重复维护字段白名单；
- 正则还隐含“值必须与字段名同行”的格式要求；
- 写侧和登记侧都没有在新简报进入索引前验证至少存在一种受支持任务语义。

因此新增任务简报可采用合理但未登记的标题或空值嵌套列表，并在索引时静默得到
无任务语义实体。此前只暴露一份 UI 简报，本轮新增工作项使同一根因扩大为四份。

## 修复边界

根因确认前不改解析器或四份任务简报。确认后应形成最小修复方案，并在第二个人工
Gate 批准后才实施与回归；不得用跳过失败测试或宽松默认成功掩盖问题。
