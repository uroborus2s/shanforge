# TEST-GOVERNANCE-001

## 目标

清理测试计划和案例目录中的旧平台测试引用，统一当前 Skill 工程的测试案例、状态与报告合同，并用可执行守卫保证正式测试入口真实存在。

## 验收标准

- 正式测试计划不再把已删除的 `src/` 平台测试列为当前执行入口。
- 测试案例、批次结果和测试报告的状态语义明确且一致。
- 文档模板能产出人类可读、可追踪、可审批的测试案例和测试报告。
- 治理测试能拒绝不存在的测试入口和陈旧平台引用。
- 当前工作区与提交后的干净克隆均通过完整测试和静态门。

## 范围

- 正式测试计划、测试文档模板和相关 Skill 合同。
- 测试治理回归测试与陈旧案例目录清理。
- 本工作项计划、证据、评审、状态和本地提交。

## 非目标

- 不恢复旧 `src/` 平台运行时或旧平台测试。
- 不新增测试框架、依赖、服务或中心脚本。
- 不执行 push、PR、merge、部署或生产动作。
