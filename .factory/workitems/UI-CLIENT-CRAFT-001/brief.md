# UI-CLIENT-CRAFT-001 · 页面设计与美术质量优化
## 授权与目标
用户要求结合当前讨论给出并实施优化方案。本工作项优化 Shanforge 的 UI skill；ita-club 教练端仅作只读事实和独立样板输入，不修改其业务代码、已确认首页、数据库或素材包。
将“基础组件堆砌”改为可执行的页面构图、真实参考学习、素材职责与双层视觉验收。技能机制完成与人类美术认可分别报告。
## 已确认问题
教练交付稿大量使用等权白卡；日程的时间关系未成为视觉主体；学员训练数据已有等级、观察和复盘，但交付稿未呈现。Taro 源码已显示部分观察与最近复盘，不能把设计稿问题直接宣称为真机缺陷。
## 验收标准
- 区分任务用途与表达强度，operate 不等于粗糙后台；基本组件复用不等于页面模板复用。
- 核心对象、内容优先级和关系映射到布局；不虚构业务数据、指标或交互。
- 参考学习必须实际观察并形成项目转化；图片无法查看时标缺口，不假称研究完成。
- 新设计使用真实内容关键页和普通业务页验证；局部修复与批准基线扩展不被强制重设计。
- 位图按需，控件和文字保持原生或代码；平台/许可/素材确认边界不变。
- 设计质量、实现还原、功能验证分开；测试或 AI 自评不能替代人工美术确认。
- 独立执行者用新版 skill 制作一个含三页的教练端候选样板，实际浏览器查看并记录不足。它是迁移试做，不是同模型同预算 A/B，也不是正式产品交付。
## 非目标
不改 BM25/CLI、全局宿主配置或业务 API；不安装外部 skill、依赖；不复制第三方品牌/资产；不声称彻底消除模板化。
