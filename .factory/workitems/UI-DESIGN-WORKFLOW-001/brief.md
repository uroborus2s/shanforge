# UI-DESIGN-WORKFLOW-001：收紧 UI 设计工作流表述

## 目标

用最小改动明确两条通用规则：先确认代表性关键页面，再批量扩展；界面设计与最终美术资源生产分别路由。

## 范围

- 补充通用设计流程的关键页面确认门。
- 消除 `ui-ux-pro-max` 与 `art-asset-pipeline` 的路由重叠。
- 增加最小语义测试。
- 由未参与实现的中文语言专家独立评审文字的简洁性、准确性和无歧义性。

## 非目标

- 不修改 `art-asset-pipeline` 的既有流程。
- 不修改移动端高保真资源生产流程。
- 不新增设计工具、运行时、依赖或模板。

## 验收标准

1. 通用设计流程明确：先完成少量代表性关键页面并确认视觉与组件规则，再扩展其余页面和平台。
2. 普通控件与通用图标默认由代码、平台能力或既有图标库实现，不进入位图切图资源包。
3. `using-shanforge` 对 UI/UX 设计和美术资源生产的路由条件互不重叠。
4. 定向测试通过。
5. 独立中文语言专家确认文字简洁、准确、无重复或歧义。
