# T06：移动端高保真视觉升级

- 目的：把现有移动端流程骨架升级为可开发、可验收的高保真界面，不用 `*.penpot` 代替美术资源。
- 本轮交付：三套方向样张，每套包含首页、服务详情、订单详情。
- 平台：iOS、Android、微信小程序共用品牌与美术方向，导航、控件和交互分别遵守平台规范。
- 保留：现有需求 ID、UI ID、页面结构、失败恢复和无障碍要求。
- 禁止：确认前覆盖 Penpot 画板、生成最终资源包、写入 `approved/`、把候选方向写成正式规范。
- 人工 Gate：用户选择一个方向，或要求定向重做；未选择时状态为 `needs_user_input`。
