# 设计案例观察边界

核对日期：2026-09-05。以下是原始来源学习证据，不是当前产品美术验收。

- https://www.cogapp.com/work/mit-museum ：读取原作者文字，并在 CUA 隐藏 IAB 中实际查看 1280×720 顶端案例截图。观察到强黑色字标构成版面边界、馆藏物件图像成为焦点、非对称留白及粉/黄色内容区；未访问实际馆藏应用或测交互。
- https://linear.app/now/how-we-redesigned-the-linear-ui ：读取 2024-03-28 原文，并通过案例页 image “Introducing the new Linear UI” 查看放大的透视产品展示图。观察到窄侧栏、密集 Inbox、右详情的三栏结构，选中行底色、头像、少量状态色；未测试实时产品，未测像素尺寸/对比度，未执行 before/after 视觉比较。
- https://developer.apple.com/design/awards/2025/ ：仅阅读原文，CapWords、Mela、Art of Fauna 是继续研究线索；未使用对应 app，不能写成实际看过的页面或验证结果。

参考图没有下载或复制入素材包。视觉观察由工具原生截图支持，没有伪造本地截图路径。来源不可用时必须保留证据缺口；后续产品设计需要针对自己的目标页面重查，而非直接套用这些案例。
