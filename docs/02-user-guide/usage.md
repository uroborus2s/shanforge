# 使用说明

## 1. 最常见的使用方式

1. 让 AI 先读取项目规则、状态和相关文档。
2. 用自然语言描述目标。
3. 让 AI 选择合适的 `factory-*` 命令推进任务。
4. 把结果同步回代码、文档、测试和 `.factory/memory/`。

## 2. 常见场景

- 新项目初始化
- 历史项目纳管
- 需求补齐
- 设计补齐
- 缺陷修复
- 变更分析
- 发布前检查
- 交接和复盘

## 3. 使用建议

- 不确定下一步时，优先使用 `factory-agent-session` 或 `factory-state-doctor`
- 已知目标但不想记命令时，优先使用 `factory-dispatch`
- 重要变更必须同步更新正式文档
