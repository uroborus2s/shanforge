## 文档职责

- 允许保存：稳定公共接口；函数与命令入口；兼容约束。
- 禁止保存：内部候选接口；实现私有细节；重复 API 设计。
- 主要读者：集成方、开发者。

## 正式内容

## 1. 说明范围

这里只记录“稳定可调用”的函数入口，不记录私有 helper。

包括：

- CLI 命令入口
- 稳定脚本入口
- 插件 Hook
- 对外暴露的函数或服务调用点

## 2. 每个函数入口至少说明

- 名称
- 作用
- 参数
- 返回结果
- 失败语义
- 副作用
- 示例
- 版本与兼容约束

## 3. 变更要求

以下变化必须同步更新本页和相关接口文档：

- 参数变化
- 返回值变化
- 错误语义变化
- 权限和鉴权变化
- 幂等、超时、重试变化

---

## 1. 对外接口

对外接口文档用于给集成方和开发者阅读，重点回答：

- 能调什么
- 怎么调
- 需要什么鉴权
- 返回什么
- 失败时怎么处理
- 版本怎么兼容

## 2. 与内部设计文档的关系

- 面向开发者的人类说明放在本模块。
- 面向内部研发和架构的详细接口设计放在 [API 设计文档](../05-design/api-design.md)。
- 机器契约文件和系统级接口约束放在 `项目开发文档（内）/设计文档` 下的契约目录。

## 3. 变更同步规则

接口发生以下变化时，必须同步更新：

1. 对外接口说明
2. 内部接口设计文档
3. 契约文件
4. 测试用例与发布说明
