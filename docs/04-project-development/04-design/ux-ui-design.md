# UX/UI 设计文档

## 1. 文档目标

说明 `v2` 抽象 Agent 平台未来面向操作者、业务配置者与平台维护者的交互表面。

## 2. 核心交互对象

- 平台操作者：查看运行状态、审批、会话与执行结果
- 业务配置者：编写 `Agent App Manifest`、`Workflow DSL`、`ModelPolicy`
- 平台维护者：配置能力注册、模型供应商、沙箱和审计策略

## 3. 关键交互场景

1. 创建或编辑 `Agent App`
2. 组合业务工作流并选择每一步的模型策略
3. 查看一次运行的上下文、步骤轨迹、工具调用与结果
4. 处理高风险动作审批、失败恢复和重试

## 4. 设计要求

- 平台界面必须优先暴露工作流结构、当前步骤、模型选择和证据输出。
- 业务流配置必须支持低门槛创建，同时保留对高级策略、审批与工具权限的显式控制。
- 运行态必须能区分用户输入、上下文装配、模型响应、工具调用和最终 `AgentResponse`。
- 审批、失败、恢复和重试必须是显式状态，而不是隐藏在日志里。
