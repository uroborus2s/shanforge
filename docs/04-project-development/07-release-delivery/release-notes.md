# 发布说明

**项目名称：** 山海工枢 / shanforge

**负责人：** 仓库维护者
**主要读者：** 维护者 | 项目协调者 | 测试

## 1. 当前发布结论

本次不是功能发布，而是 `v2` 产品定义重置。发布说明的作用是确认：

- `v2` 已切换为单一抽象 Agent 平台产品定义
- 正式文档已切换为纯抽象 Agent 平台方向
- 后续实现与测试将围绕新平台契约推进

## 2. 本次变更

- 重写 `PRD`、需求分析、需求校验
- 重写总体方案、系统架构、平台架构、模块边界和 API 设计
- 重写实施计划、测试计划和追踪矩阵
- 将旧实现降级为遗留适配器事实，不再作为产品中心

## 3. 后续发布条件

进入真正的 `0.2.0` 发布候选前，需要至少满足：

- 平台内核主闭环可运行
- Workflow DSL、ModelPolicy、Capability Registry 契约冻结
- Demo Agent Apps 可在本地测试环境下通过
- AgentResponse 与 evidence 链路可回放
