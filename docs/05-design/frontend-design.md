## 文档职责

- 描述当前静态项目快照的前端边界。
- 不定义独立 Web 应用、前端服务或构建产物。

## 当前设计

`skills/using-shanforge/scripts/project_snapshot.py` 从目标项目登记事实生成只读 HTML。页面只显示可读的项目状态、任务、阻塞与下一动作；不提供编辑、审批、提交、发布或外部调用入口。输入不变时复用缓存，输出属于 `.factory/cache/site/current/` 的可重建投影。

若目标项目需要实际产品 UI，专项 UX/UI skill 负责其设计方法和验收；该设计不把候选设计工具文件登记为 Shanforge 正式资产。

## 适用验证

- 快照脚本定向 pytest。
- 界面相关测试验证 390px 与 1440px 的无页面级横向溢出和键盘入口。
