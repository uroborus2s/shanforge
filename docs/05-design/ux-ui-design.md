## 文档职责

- 定义当前静态快照的信息优先级和目标项目 UI 的工作方法。
- 不保留未连接设计工具候选、token、导出物或其正式资产资格。

## 当前设计

当前快照优先展示：项目状态、活动任务、阻塞和唯一下一动作；细节链接到可审计的正式文档与 ledger。页面必须保留足够对比度、键盘可达性、焦点可见性、窄屏可读性和空态/错误态说明。

目标项目的 UI 需求由 `ui-ux-pro-max` 或项目已有设计系统在具体任务中处理：先识别用户流、信息架构、状态和可访问性，再选择项目内已有实现方式。没有当前消费者的候选设计文件不属于正式设计资产。

## 适用验证

- 快照的 UI 定向测试。
- 人工或自动检查主入口键盘可达及 390px/1440px 布局。
