# 文档地图

## 1. 四大模块

请逐项说明以下模块分别服务谁、解决什么问题：

1. `01-getting-started`
2. `02-user-guide`
3. `03-developer-guide`
4. `04-project-development`

## 2. 推荐阅读顺序

- 第一次接触项目：先看 `01-getting-started`
- 需要实际使用：看 `02-user-guide`
- 需要开发或集成：看 `03-developer-guide`
- 需要参与需求、设计、测试、发布和运维：看 `04-project-development`

## 3. 内部模块说明

对 `04-project-development` 下的治理、调研、需求、设计、开发过程、测试、发布、运维、演进和追踪矩阵分别给一句话解释。
