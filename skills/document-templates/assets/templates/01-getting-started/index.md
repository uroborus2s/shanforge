# 入门说明

本目录面向第一次接触项目的读者，回答三个问题：这是什么、先看什么、怎么开始。

## 1. 适合谁先看

- 第一次接手本项目的维护者
- 需要快速判断项目边界的协作者
- 需要在更细文档前先建立整体心智模型的读者

## 2. 推荐阅读顺序

1. [项目概览](./project-overview.md)
2. [快速开始](./quick-start.md)
3. [文档地图](./document-map.md)

## 3. 阅读完成后的预期

读完本目录后，应能知道：

- 项目解决什么问题
- 正式文档应该从哪里进入
- 下一步应该去用户指南、开发者指南还是内部项目文档
