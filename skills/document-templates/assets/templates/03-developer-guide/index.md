# 开发者指南

本目录面向需要扩展、集成或二次开发项目的开发者，聚焦稳定开发入口，而不是内部过程细节。

## 1. 什么时候启用本目录

- 项目存在公开 API、SDK、MCP tools 或函数入口
- 项目存在插件机制、模块扩展点或二次开发场景
- 需要给外部或跨团队开发者提供稳定说明

## 2. 推荐内容

- 应用开发
- 开发环境
- 函数说明
- 接口说明
- 插件开发
- OpenAPI / MCP tools 契约说明

## 3. 与内部文档的边界

本目录只保留稳定可调用、可协作、可集成的信息；需求、设计、测试、发布和运维细节统一落在 `../04-project-development/index.md`。
