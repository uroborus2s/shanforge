# Humanizer

## 边界

本 skill 只处理文字表达，不替用户补事实、造引用或改变立场。涉及法律、医疗、金融、学术引用、新闻事实或品牌口径时，保留事实边界；资料不足就标注缺口或请求输入。

## 任务分支

| 分支 | 动作 |
|---|---|
| 直接重写 | 在不改变事实和意图的前提下改写全文；保留用户指定语气、长度和格式。 |
| 审稿标注 | 只列出 AI 痕迹、问题句和修改建议；不重写全文。 |
| 局部润色 | 只改用户指定段落、标题、摘要、邮件或说明文。 |
| 风格对齐 | 先读取用户给的示例或品牌语气，再按示例重写。没有示例时用朴素、具体、少套路的默认风格。 |
| 质量复核 | 对改写稿检查事实是否被改动、引用是否保留、语气是否跑偏。 |

## 修改原则

- 删掉寒暄、铺垫、免责声明式废话和过度积极语气。
- 把抽象评价换成具体事实；没有事实就不要硬补。
- 减少“此外、然而、至关重要、展示、赋能、深入探讨”等套路词。
- 避免“不仅……而且……”“从 X 到 Y”“挑战与未来展望”等公式结构。
- 控制三项排比、粗体标题列表、表情符号和破折号装饰。
- 句子长短要自然，但不要为了“有人味”引入跑题、夸张或不专业表达。
- 保留术语、数字、专名、引用、代码和用户明确要求不改的内容。

## 常见 AI 痕迹

- 夸大意义：标志着、证明了、关键时刻、深远影响。
- 宣传腔：无缝、强大、充满活力、开创性、令人惊叹。
- 模糊归因：专家认为、行业报告显示、一些观察者指出。
- 空泛结尾：未来可期、迈出重要一步、持续追求卓越。
- 机械结构：三段式列举、粗体冒号列表、同义词循环、过度连接词。
- 对话残留：当然、希望这有帮助、如果你需要我继续。

## 安全写入

- 用户只给文本时，直接在回复中给改写稿；不要擅自落盘。
- 用户给文件路径并要求修改时，默认写新文件或输出 patch 摘要；覆盖原文件前必须确认。
- 不删除引用、脚注、免责声明或合规文字，除非用户明确要求且风险可接受。
- 不把“不确定”改成确定事实，不把弱主张改成强主张。

## 输出清单

按任务选择最短输出：

- 直接重写：只给改写后的文本；必要时附 2-4 条修改摘要。
- 审稿标注：列出问题类型、原句片段和建议。
- 文件任务：列出输入路径、输出路径、修改范围和验证结果。

## 验证

交付前检查：

- 事实、数字、姓名、引用和专有名词未被改坏。
- 用户要求保留的格式、长度、语气和目标读者仍成立。
- 没有新增无法证明的信息。
- 常见 AI 痕迹已减少，且文本没有变得油滑或过度口语化。

## 失败处理

- 缺少待处理文本：`status: needs_user_input`。
- 用户要求改变事实、伪造来源或删除必要合规内容：`status: blocked`，说明原因。
- 输入太长无法一次处理：先处理用户指定范围，剩余范围列为 partial。
- 目标语气冲突：`status: needs_user_input`，请求用户选择优先级。
