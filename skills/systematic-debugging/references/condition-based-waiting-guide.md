# 条件等待

用于处理异步、并发和 flaky 测试。原则是等待真实条件，不要猜时间。

## 何时使用

- 测试里出现 `sleep`、`setTimeout` 或固定等待。
- 测试偶发失败。
- 并行执行时超时。
- 等待事件、状态、文件、计数或异步结果。

## 模式

```text
等待条件：
- 事件出现
- 状态变为 ready
- 计数达到预期
- 文件存在
- 对象字段满足条件
```

## 要求

- 每次轮询都读取新鲜状态。
- 必须有超时错误。
- 超时错误说明等待的条件。
- 轮询间隔要合理，避免忙等。
- 只有测试真实时间行为时，才能保留固定等待，并说明原因。

## 禁止

- 不要猜时间。
- 不要没有超时。
- 不要缓存旧状态后循环。
- 不要用固定等待掩盖根因。
