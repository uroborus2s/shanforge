# 全渠道生活服务平台样例

本目录是 `ui-ux-pro-max` 的完整参考实现，演示同一业务如何交付 Android、iOS、微信小程序和管理后台设计，以及如何将需求、设计、API、测试、发布与运维装入一个可裁剪的 `docs/`。

## 使用方式

1. 从 [文档入口](docs/index.md) 理解完整交付链。
2. 在 Penpot 中加载 MCP 插件，运行 [`tools/build-penpot-example.js`](tools/build-penpot-example.js) 构建设计样例。
3. 复制本样例时按项目事实删除不适用文档，不要保留空壳。
4. 真实项目必须替换样例 ID、数据、截图、测试结果和发布信息。

## 按项目裁剪

| 项目事实 | 创建的文档 |
|---|---|
| 所有正式项目 | 文档入口、项目概览、需求、方案总览、实施计划、测试计划/报告、追踪矩阵 |
| 有最终用户操作 | 用户指南、UX/UI 设计、平台矩阵、设计系统 |
| 有管理或运维角色 | 管理员指南、权限/审计设计、运维手册 |
| 对外或跨模块提供 HTTP API | 接口参考、API 设计、OpenAPI |
| 有数据库或持久化状态 | 数据设计、迁移与回滚约束 |
| 需要部署和发布 | 发布说明、部署指南、回滚计划 |
| 使用 Penpot 做正式设计 | Penpot 交接、设计资产清单；导出成功时才保存预览 |

没有对应项目事实就不创建文档。需求变化修改原 PRD 和关联文档并增加版本历史；索引、矩阵、SQLite 和 HTML 都是引用或派生视图，不能成为第二份需求正文。

## 重要边界

- 这是教学与模板样例，不是已上线产品。
- `test-results.json` 和 `test-report.md` 展示格式，不代表真实测试通过。
- Penpot 页面是设计事实；导出图只是便于仓内审阅的快照。当前 MCP 的 PNG/SVG 导出均返回 `http error`，因此没有提交伪造或空白预览。
- OpenAPI 是可解析契约样例，不包含真实服务实现。
