# 移动端高保真候选方向

本文件保存可复现的候选定义。用户已于 2026-07-24 确认“以 B 为基础，吸收 A 的温暖摄影风格和 C 的少量材质感”；正式方向见 [`art-direction.md`](art-direction.md)。

## 共同画面与内容

- 横向设计评审板，并排展示三个完整移动端页面，不使用实体手机模型和透视变形。
- 页面一：首页，品牌“悦享服务”，突出服务发现、分类和可信服务照片。
- 页面二：服务详情“肩颈舒缓理疗”，显示服务人员、评分、`¥168`、可约时间和预约按钮。
- 页面三：订单详情，显示订单号 `YX202607240018`、状态“待服务”、进度时间线、联系和取消入口。
- 简体中文；高保真产品界面；真实层级、间距、图像裁切、颜色、材质、阴影和组件状态。
- 排除：低保真线框、荧光渐变堆砌、玻璃拟态滥用、不可读文字、装饰性 3D 图标、品牌水印。

## A：温润生活方式

- 色彩：暖象牙白、陶土珊瑚、鼠尾草绿、深棕灰。
- 影像：自然日光下的真实生活服务摄影，肤色自然，空间温暖干净。
- 气质：可信、亲近、有品质；轻圆角、克制阴影、留白充足。

## B：现代城市服务

- 色彩：冷白、深靛蓝、钴蓝、青绿色点缀。
- 影像：清晰的城市生活编辑摄影，构图利落，信息密度适中。
- 气质：专业、高效、清醒；分区明确，状态反馈强，避免企业后台感。

## C：东方疗愈轻奢

- 色彩：暖石色、米白、玉石绿、墨色、少量桃金。
- 影像：自然材质、植物、光影和理疗场景，避免符号化传统装饰。
- 气质：安静、精致、有触感；纸张和矿物质感仅用于美术层，不影响可读性。

## 人工选择标准

1. 一眼看懂服务是什么、多少钱、下一步做什么。
2. 图片与品牌气质统一，不像素材拼贴或线框稿。
3. 中文标题、价格、状态和主按钮清晰。
4. 能稳定派生 iOS、Android、微信小程序，而不是只适合单张海报。
5. 美术层与组件层可分离，后续能形成可追溯资源清单。
