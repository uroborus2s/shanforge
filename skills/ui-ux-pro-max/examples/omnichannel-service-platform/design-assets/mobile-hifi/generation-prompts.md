# 最终资源生成记录

生成方式：Codex 内置 `imagegen`，基于用户已确认的三张 `approved/` 方向图。
所有图禁止文字、商标、水印和 UI 烘焙。

## 母图与用途

| Prompt ID | 母图 | 用途 |
|---|---|---|
| `neck-service-v1` | 肩颈服务真实场景 | 首页、肩颈卡片、详情主图 |
| `cleaning-v1` | 日常保洁真实场景 | 保洁卡片 |
| `appliance-v1` | 无品牌空调滤网清洁 | 家电清洗卡片 |
| `environment-v1` | 暖光城市居住空间 | 服务环境详情 |
| `hygiene-v1` | 一次性面托套、毛巾和卫生工具 | 工具与卫生详情 |
| `provider-li-v1` | 同一服务者自然光正面头像 | 服务者头像 |
| `surface-mineral-v1` | 低对比暖石纸张纹理 | 6% 以下页面底纹 |

## 稳定约束

- 同一成年中国女性服务者，深靛蓝无标识制服，暖自然光。
- 真实上海城市住宅；专业但不做 SPA、医疗或棚拍广告。
- 人物和动作位于中心安全区，支持 3:2、4:3 和 16:9 裁切。
- 纹理无焦点、低对比，最终通过镜像拼接形成确定性无缝派生。
- 详细 prompt 保存在本次任务的 imagegen 调用记录中；最终文件以 manifest
  中的 SHA-256、Prompt ID 和确认来源追溯。
