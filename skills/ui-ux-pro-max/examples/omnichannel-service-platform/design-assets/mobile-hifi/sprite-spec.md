## 确定性导出

- JPEG 源图按端内图片管线派生 WebP/HEIF 等运行格式；不把同一内容重复生成为三套不同人物。
- 首页和详情图保留 3:2、4:3、16:9 裁切安全区；主体、手部和服务动作不得被裁断。
- 深色模式优先使用遮罩和 token 调整；只有照片对比度实测不合格时才生成暗色派生。
- 所有图片禁止内嵌标题、价格、按钮、状态、图标和水印。
- 订单状态卡片、时间线、导航、分类图标和按钮均由组件与既有图标库实现，不生成位图。

## 不在本批次

- 品牌 Logo、启动页、营销海报：当前没有已批准的品牌标志或营销需求。
- 动态背景、Lottie/Rive：核心流程不需要，确认存在品牌动效需求后再增加。
- 空状态插画：先用图标、标题和恢复操作完成可用性验证，确有品牌价值时另提清单。

## 验收

- 每张图与 `art-direction.md` 的确认来源可追溯。
- 人物、服装、空间、光线和色彩在同一服务组内连续。
- 无错字、伪文字、商标、水印、畸形手部和不合理服务动作。
- 关键裁切在 iOS、Android、微信小程序目标比例下均保留主体。
- 文件尺寸、格式、色彩空间和授权/生成记录进入最终 `manifest.json`。
