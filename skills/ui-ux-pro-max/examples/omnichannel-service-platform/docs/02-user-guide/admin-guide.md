## 角色

| 角色 | 允许操作 |
|---|---|
| 运营 | 查看指标，维护服务与价格 |
| 客服 | 查看脱敏订单，联系客户，提交售后 |
| 财务 | 查看支付流水，审核退款 |
| 平台管理员 | 管理角色、权限和审计日志 |

## 订单处理

1. 在订单列表按状态、日期、渠道或服务筛选。
2. 进入独立订单详情页，不使用侧边抽屉承载完整详情。
3. 核对支付、履约、客户隐私和售后状态。
4. 执行取消或退款前必须二次确认，并记录原因。

## 服务管理

- 草稿服务不会出现在客户端。
- 修改价格必须填写生效时间，已创建订单保持原成交价。
- 删除改为下架；存在历史订单的服务不得物理删除。

## 审计

价格、权限、退款和订单状态变更必须记录操作者、时间、来源 IP、变更前后值和业务原因。
