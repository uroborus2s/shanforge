## 完成一次预约

1. 在首页搜索或选择服务分类。
2. 在详情页确认服务内容、价格、取消规则和人员资质。
3. 选择服务人员、日期、时间与地址。
4. 确认订单金额后支付。
5. 在支付结果页保存订单号，并可进入订单详情。
6. 在订单详情查看接单、出发和完成状态。

## 支付中断

- 返回结果不明确时不要重复提交。
- 进入“订单”查看是否已创建；系统通过幂等键避免重复订单。
- 微信支付回跳失败时，从小程序“我的订单”恢复。

## 取消与退款

- 订单详情会显示当前可取消规则和预计退款金额。
- 已开始服务时不能直接取消，应提交售后申请。
- 退款进度在订单详情持续更新。

## 隐私与权限

- 地址、手机号在非必要场景脱敏。
- 拒绝定位不阻断预约，可手动选择地址。
- 拒绝通知后仍可在订单详情查看进度。

## 无障碍

所有关键操作提供可见标签、键盘/屏幕阅读器名称和非颜色状态提示；减少动态效果时改用短淡入或即时状态。
