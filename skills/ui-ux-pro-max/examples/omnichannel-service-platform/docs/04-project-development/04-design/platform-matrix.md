## 共享

共享 REQ/AC、内容模型、业务状态、OpenAPI、错误 code、语义 Token、组件角色、分析事件和无障碍意图。

## 必须分叉

导航容器、系统返回、权限流程、支付调用、通知授权、系统控件、包体/窗口约束和发布审核。

## 验收设备

- iOS：最小与常规屏、最大 Dynamic Type、VoiceOver、深色模式。
- Android：常规手机与大屏窗口、最大字体、TalkBack、手势导航。
- 微信：iOS 与 Android 真机、最低支持基础库、弱网、前后台和支付回跳。
- 后台：主流 Chromium、Safari/Firefox（若声明支持）、键盘、200% 字体、400% 页面缩放。
