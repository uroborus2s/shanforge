## 版本摘要

计划首次提供服务发现、预约、支付恢复、履约、售后和运营管理闭环，覆盖 iOS、Android、微信小程序与管理后台。

## 用户可见变化

- 消费者可查看服务、选择人员和时间、创建订单并跟踪支付与履约。
- 网络或支付回跳中断后，可回到订单详情恢复最终状态。
- 运营人员可通过中文业务标题的列表和独立详情页处理订单。
- 管理员可控制高风险操作权限并查询审计记录。

## 契约与数据变化

- 新增公共 API `v1`，契约见 [OpenAPI](../../03-developer-guide/openapi/public-v1.openapi.yaml)。
- 新增服务、人员、库存、订单、支付、退款、事件和审计数据。
- 订单保存价格和政策快照，后续服务配置变化不回写历史订单。

## 兼容性

具体最低系统、基础库和浏览器版本必须由实际客户端项目确定并在发布候选验证；本文档样例不虚构版本号。
