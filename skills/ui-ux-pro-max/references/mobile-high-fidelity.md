# 移动端高保真设计

## 交付边界

- Penpot 承载页面结构、组件、token、交互、状态和平台映射；它不能替代摄影、插画、纹理或品牌美术。
- `imagegen` 生成的整页 UI 只用于视觉方向确认，不能直接当组件稿、开发切图或含真实文案的最终页面。
- 视觉样板用于确认画面方向；正式摄影、插画或纹理资源在方向和资源清单确认后生产。两者均不替代可编辑设计源和实现还原验收。
- 最终界面必须把可实现的组件层与可追溯的美术资源层分开；文字、价格、状态、按钮和图标不得烘焙进背景图。
- 图标优先使用目标平台或项目既有图标库；简单、可维护的品牌或装饰图形可作为自有 SVG。共享的素材职责、来源和许可见 [设计流程与交付物](design-workflow-and-deliverables.md)。

## 固定流程

1. 先完成任务流、信息架构、页面清单和状态矩阵，保留低保真及可编辑候选作为结构骨架；不覆盖已批准设计源。
2. 通用方向比较、素材清单和交付边界遵循 [视觉方向与质量](visual-direction-and-quality.md) 与 [设计流程与交付物](design-workflow-and-deliverables.md)；已有授权不重复确认。
3. 分别验证 iOS、Android、小程序的安全区、导航、触控目标、字体缩放、返回语义、性能和 reduced motion；共享品牌，不共享一套机械缩放的像素稿。

## 高保真验收

- 页面在不读说明的情况下能看懂“这是什么、多少钱/什么状态、下一步做什么”。
- 图片有统一主体、光线、裁切和授权来源，不像无关素材拼贴。
- 视觉层级由真实内容、间距、字体、颜色、材质和组件状态共同建立，不靠渐变、玻璃拟态或装饰性 3D 堆砌。
- 首页之外至少交付核心详情、过程状态、异常和恢复；漂亮首页不能代表完整产品。
- 生成图中的错字和伪文字只能作为方向样张缺陷，正式组件稿必须使用真实文案重新排版。
- Penpot 画板、资源文件、需求、页面 ID 和实现组件之间可追溯。
- 先以同视口截图验收设计质量，再独立验收实现对组件、状态、交互和适配的还原；自动化测试和作者自评不替代任一视觉验收。

## 最小交付物

- 已确认的美术方向和确认来源。
- 待确认或已确认的资源清单：文件名、用途、尺寸、格式、透明度、裁切安全区、明暗模式和派生关系。
- 可编辑设计源或项目链接，并标明版本，以及页面/组件/状态/交互稿和平台差异矩阵；PNG/PDF 页面图只作预览。
- `assets/` 下的资源 manifest、许可或生成记录、关键页面预览和实际验证证据。
