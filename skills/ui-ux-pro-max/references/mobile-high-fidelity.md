# 移动端高保真设计

## 交付边界

- Penpot 承载页面结构、组件、token、交互、状态和平台映射；它不能替代摄影、插画、纹理或品牌美术。
- `imagegen` 生成的整页 UI 只用于视觉方向确认，不能直接当组件稿、开发切图或含真实文案的最终页面。
- 最终界面必须把可实现的组件层与可追溯的美术资源层分开；文字、价格、状态、按钮和图标不得烘焙进背景图。
- 图标优先使用目标平台或项目既有图标库；只有品牌独有图形才进入美术资源包。

## 固定流程

1. 先完成任务流、信息架构、页面清单和状态矩阵，保留低保真稿作为结构骨架。
2. 需要品牌化或真实美术时，调用 `art-asset-pipeline` 和 `imagegen` 生成 2–4 套方向样张。
3. 样张至少展示一个发现页、一个内容/服务详情页和一个状态/订单详情页；检查中文标题、价格、状态和主操作是否一眼可懂。
4. 未经用户明确选择，不覆盖 Penpot、不写入 `approved/`、不生产最终资源包。
5. 方向确认后，写 `art-direction.md`，再提交资源清单；清单确认前不批量生成资源。
6. 资源清单确认后，生产图片、插画、纹理和品牌资产，建立 manifest，再把资源引用和组件规范同步到 Penpot。
7. 分别验证 iOS、Android、小程序的安全区、导航、触控目标、字体缩放、返回语义、性能和 reduced motion；共享品牌，不共享一套机械缩放的像素稿。

## 高保真验收

- 页面在不读说明的情况下能看懂“这是什么、多少钱/什么状态、下一步做什么”。
- 图片有统一主体、光线、裁切和授权来源，不像无关素材拼贴。
- 视觉层级由真实内容、间距、字体、颜色、材质和组件状态共同建立，不靠渐变、玻璃拟态或装饰性 3D 堆砌。
- 首页之外至少交付核心详情、过程状态、异常和恢复；漂亮首页不能代表完整产品。
- 生成图中的错字和伪文字只能作为方向样张缺陷，正式组件稿必须使用真实文案重新排版。
- Penpot 画板、资源文件、需求、页面 ID 和实现组件之间可追溯。

## 最小交付物

- 已确认的 `art-direction.md` 和确认来源。
- 待确认或已确认的资源清单：文件名、用途、尺寸、格式、透明度、裁切安全区、明暗模式和派生关系。
- Penpot 页面/组件/状态/交互稿，以及平台差异矩阵。
- 资源 manifest、许可或生成记录、关键页面预览和实际验证证据。
