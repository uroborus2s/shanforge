# 视觉方向与质量

## 先分流，再选视觉

| 任务 | 最小动作 |
|---|---|
| 新建或整体重设计 | 先确定平台约束，默认为一个关键页比较三种方向；已有批准方向或用户明确预算可减少。 |
| 已批准基线的扩展 | 继承已确认的构图、品牌和组件规则，只补页面/状态。 |
| 局部修复 | 直接修复受影响组件或状态，不重做页面视觉。 |
| 只读评审 | 记录证据与建议，不写设计或资产。 |

默认三种方向使用同一内容和同一视口。它们在构图、信息组织、字体或影像上至少有一项实质不同；仅换色不算。默认每方向只做一个关键页，选定后再扩展状态和平台。已有选择不重复要求确认。

新 UI、整体重设计，或用户明确把某批页面退回为粗糙/组件堆砌时，代表性样板须覆盖实际高频普通业务页，以及信息复杂或关键状态；同一页可同时覆盖这些条件，不设固定页数、卡片数或装饰配额。已批准且未被退回的首页和基线继续保留，局部排版修复不触发全套流程。收到粗糙反馈时，先在该范围返回可见样板和具体画面问题的整改；在适用的人类确认门前，不扩成整批页面。

| surface | 任务与优先级 |
|---|---|
| `persuade` | 说清价值、建立信任、引导转化；先验证主张、证据与主操作。 |
| `operate` | 快速处理高密度信息；先验证扫描、筛选、状态和错误恢复。 |
| `read` | 阅读、理解或学习内容；先验证标题层级、节奏、长文与定位。 |
| `experience` | 沉浸式探索或创作；先验证内容主体、直接操作、反馈和降级。 |

方向记录必须按“产品事实 → 参考方法 → 布局骨架/字体层级/CJK/影像主体/1–2 识别点 → 反方向 → 平台约束 → 截图和行为验证”写出。3D、渐变、Inter 或圆角并非天然 AI 化；只有缺少任务或品牌依据、干扰内容/可用性时才是问题。

## 从业务关系到实际画面

先列出用户要处理的业务对象、对象关系、决策顺序和异常，再把它们转成可见构图：谁是页面主体、哪些关系需要同屏比较、哪些信息只在进入下一步后出现，以及状态如何改变操作优先级。不要从卡片、banner 或商品类型反推业务页面。`operate` 页面服务具体工作而非“后台感”；没有图片的工具页可通过分组、留白、字体层级、密度和反馈做到克制而清晰。

真实看图参考只可学习可观察的方法，随后写成本项目的对象、内容、平台和实现限制下的转化，并保留不照抄项。样板用于比较视觉方向，正式摄影/插画/纹理资源用于实现；二者都不能代替可编辑组件、真实文案和状态设计。

原稿问题观察与优秀案例学习是不同证据：前者说明待修画面的具体缺陷，后者必须基于实际看过的优秀界面或案例并记录可转化方法。没有实际优秀参考时，明确这一缺口；旧失败稿或链接列表不能冒充完成。局部调整不因此强制浏览找图。

## 少量案例的可追溯学习

每个新方向只选少量互补案例：同领域优先验证可用性，跨领域可学习视觉表达。每条记录 URL、日期、证据层级、实际看到的页面/交互、可学习方法、适用条件、项目转化和禁止照抄项。打不开页面或未能看图时明确缺口；链接数量、Star 和获奖不能代替观察。

## 画面与资源检查

- 日常交付先以实际截图做 critic，列最多三项优先问题，修改后用同视口复核。清晰内容、可读排版、资产一致、基本交互任一未达到时不得只凭自评推进。
- 设计质量验收与实现还原验收分开：前者检查实际画面的构图、内容层级、排版、影像和细节；后者检查设计源到页面的组件、状态、交互与适配是否一致。测试、lint、构建和 AI 作者自评只能提供行为或约束证据，不能证明视觉质量。
- 中文标题使用真实长度，避免首末行只留孤字；核对字形覆盖、中文/西文/数字基线、标点与换行，不照搬英文全大写字距。以字号放大和真实混排复核，并记录字体授权。
- 影像规范写主体、镜头/视角、光线、材质、裁切与留白；生成时保存这些要求作为 prompt 依据，复用已批准资产，避免无关拼贴。文字和控件不可烘焙进图。
- 位图仅用于摄影、插画、纹理；组件、文字和通用图标为原生/代码。自有 SVG 可用于简单、可维护的品牌或装饰矢量；资源清单写分类、来源、许可和职责。

## 可复现视觉实验

fixture 固定 ID、prompt、真实样本文案/数据、页面状态、平台/栈、主/次视口、截图与行为成功条件。旧/新 skill 固定同一模型、工具和预算，产物随机标为 A/B；未参与生成的 reviewer 盲评并登记身份。

五维各记 1–5：构图层级、中文排版、内容/品牌特异性、影像一致性、细节完成度；1 为明显缺陷，3 为满足，5 为有具体证据的充分完成。新方案仅在多数维度更好且没有主要可用性回退时记 `improved`；否则记 `unchanged`、`regressed` 或 `incomplete`。保留原始截图和行为证据，不以平均分掩盖回退，未运行不计通过。
