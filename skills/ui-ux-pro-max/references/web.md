# Web 设计

## 适用范围

网站、Web 应用、管理后台、H5、PWA、嵌入式 WebView 和响应式页面。若目标是小程序，继续读取 [mini-programs.md](mini-programs.md)。

## 结构与适配

- 用内容优先级和容器行为定义适配，不只给几个固定断点截图。
- 为窄屏、常规桌面、宽屏、横屏、浏览器缩放和嵌入 WebView 说明重排规则。
- 组件优先使用流式尺寸、min/max、Grid/Flex 和容器查询；固定像素只用于有明确物理意义的细节。
- 保证页面在 320 CSS px 宽、200% 文字缩放和 400% 页面缩放时仍可操作；不能以禁止缩放解决破版。
- 区分触控、精确指针和无 hover 环境。主要操作不得依赖 hover。

## 语义与输入

- 优先使用语义 HTML 和原生控件；自定义组件必须补齐角色、名称、值、状态和键盘行为。
- 焦点顺序与视觉/任务顺序一致。弹层管理初始焦点、焦点陷阱和关闭后的焦点归还。
- 为键盘、屏幕阅读器、语音输入、触屏和指针提供同等完成路径。
- 拖放、滑动、悬浮、长按等交互必须有可见替代操作。
- 表单保留可见 label、输入目的、自动填充、字段错误、错误摘要和恢复动作。

## 响应与状态

- 导航变化必须保持当前页面、返回语义和深链可预测。
- 异步界面覆盖首次加载、局部刷新、乐观更新、冲突、超时、离线、重试和部分成功。
- 骨架只模拟真实结构；短请求不闪烁骨架，长请求不使用无期限 spinner。
- 保留布局占位，避免字体、图片、广告和异步内容引发布局跳动。

## 视觉与主题

- 使用语义色和主题 token；明暗主题分别验证对比度、边框、阴影、图表和状态色。
- 支持高对比度、强制颜色和 reduced transparency 时，核心信息不能消失。
- 文本、图标、焦点、错误和图表信息不能只靠颜色表达。
- 控制行长、标题换行、数字对齐、长单词、CJK、RTL 和复数文案。

## 动效与性能

- 优先 transform、opacity 和合成友好的属性；避免在滚动和输入期间触发布局抖动。
- 尊重 `prefers-reduced-motion`；为自动播放、长时或强烈动画提供暂停/关闭。
- 动效库只在原生 CSS/Web Animations 不足时引入；不要为一个淡入增加整套运行时。
- 在目标浏览器和代表性低端设备测量长任务、输入延迟、滚动、布局偏移和内存。

## 验收矩阵

- 至少覆盖一个窄屏触控视口、一个桌面键鼠视口和实际支持的主浏览器。
- 覆盖键盘全流程、焦点可见、屏幕阅读器关键路径、缩放、明暗主题、reduced motion 和网络失败。
- 记录浏览器、版本、视口、DPR、输入方式、语言、主题、结果和证据路径。
