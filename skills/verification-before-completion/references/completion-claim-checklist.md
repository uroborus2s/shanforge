# 完成声明检查清单

在任何完成声明前逐项核对。

## 必须满足

- 本轮已有新鲜验证。
- 已运行完整命令。
- 已读取完整输出。
- 已检查 exit code。
- 已统计失败数量、错误数量和跳过数量。
- 已记录未运行项和偏离原因。
- 需求满足已逐项核对，不只依赖测试通过。
- evidence 已写入 work item。

## 禁止表达

- 不能用 should。
- 不能用 probably。
- 不能用 seems。
- 不能说“应该好了”。
- 不能只依赖上一次结果。
- 不能只依赖子 agent 或工具报告。
- 不能把计划运行的验证写成已经通过。

## 判断

- 全部满足：可以带证据陈述结果。
- 有失败：报告失败和下一步需要。
- 有未运行项：报告 partial 和风险。
- 不知道如何验证：先输出验证计划，不声明完成。
