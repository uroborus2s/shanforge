# Red-Green Verification

用于回归测试和 TDD 场景。目标是证明测试真的能抓住问题。

## Red

先证明测试会失败。

```bash
<失败命令>
```

失败输出：

```text
<失败摘要>
```

失败原因必须符合预期：

- 预期失败原因：
- 实际失败原因：
- 是否匹配：是 / 否

## Green

再证明修复后会通过。

```bash
<通过命令>
```

通过输出：

```text
<通过摘要>
```

## 可选反证

如果需要证明回归测试有效：

1. 暂时撤销修复。
2. 运行测试，确认失败。
3. 恢复修复后再次通过。

- Red 已验证：
- Green 已验证：
- 未验证项：
- 风险：
